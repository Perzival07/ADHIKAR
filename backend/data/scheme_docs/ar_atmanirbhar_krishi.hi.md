# आत्मनिर्भर कृषि योजना (अरुणाचल प्रदेश)

## सारांश
कृषि मशीनीकरण और ट्रैक्टर/पावर टिलर के लिए 45% सरकारी अनुदान, 45% बैंक ऋण और केवल 10% किसान अंशदान।

## लाभ
कृषि उपकरणों पर 45% की सीधी सरकारी सब्सिडी।

## पात्रता
आप कृषि मशीनरी प्राप्त करने के इच्छुक अरुणाचल के किसान या स्वयं सहायता समूह हैं।

- क्षेत्र: Arunachal Pradesh
- आयु: 18+
- आय सीमा: No Limit
- आवेदन स्थिति: Open / Ongoing (Ongoing)

## आवश्यक दस्तावेज़
- **भूमि कब्जा प्रमाण पत्र** (Circle Officer): Proves active agricultural land holdings.
- **एपी जनजातीय प्रमाण पत्र** (DC Office): Validates state domicile.
- **बैंक पासबुक** (Bank Branch): Required for loan processing.

## आवेदन कैसे करें
### आत्मनिर्भर अरुणाचल पोर्टल (online)
Submit online application at dedicated state portal.
Link: https://arunachalpradesh.gov.in

### जिला कृषि अधिकारी (blockOffice)
Submit physical copy for mechanical feasibility check.

## सावधानियाँ
Selected farmers must undergo equipment orientation training before machinery hand-over.
