# Prime Minister's Employment Generation Programme (PMEGP)

## Summary
Credit-linked capital subsidy of 15% to 35% on project costs up to ₹50 Lakh for manufacturing and ₹20 Lakh for service enterprises for unemployed youth.

## Benefit
Government capital subsidy of 25% (general urban), 35% (special categories / SC/ST/women/rural), with bank loan covering the balance.

## Eligibility
You qualify as an aspiring entrepreneur aged 18+ with minimum 8th class pass establishing a new enterprise.

- Region: All India
- Age: 18+
- Income ceiling: No Limit
- Application status: Open / Ongoing (Ongoing)

## Documents Required
- **Detailed Project Report (DPR)** (Self / Chartered Accountant): Outlines capital equipment, working capital, and projected cash flow.
- **Educational Qualification Certificate (8th Pass+)** (School Board): Mandatory for projects above ₹10 Lakh (mfg) or ₹5 Lakh (svc).
- **Category / Domicile Certificate (for 35% subsidy)** (Tehsil): Required for special category subsidy claims.

## How to Apply
### KVIC PMEGP e-Portal (online)
Submit application and upload project report at kviconline.gov.in.
Link: https://www.kviconline.gov.in/pmegpeportal

### District Industries Centre (DIC) / KVIC State Office (blockOffice)
Attend DLTFC district task force meeting for project sanction.

## Caveats
Applies strictly to setting up new greenfield units. Existing units are not eligible for first tranche.
