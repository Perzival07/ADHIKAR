# गोवा सोलर रूफटॉप सब्सिडी योजना

## सारांश
घरों और आवासीय सोसायटियों की छतों पर सोलर प्लांट लगाने हेतु केंद्र के अतिरिक्त 50% तक की भारी राज्य सब्सिडी।

## लाभ
सोलर रूफटॉप लगाने पर 50% तक राज्य सब्सिडी और शून्य बिजली बिल।

## पात्रता
आप गोवा के घरेलू बिजली उपभोक्ता हैं जिनके पास उपयुक्त छत उपलब्ध है।

- क्षेत्र: Goa
- आयु: 18+
- आय सीमा: No Limit
- आवेदन स्थिति: Open / Ongoing (Ongoing)

## आवश्यक दस्तावेज़
- **नवीनतम बिजली बिल** (Electricity Department Goa): Consumer number must be clear.
- **गृह कर रसीद / स्वामित्व प्रमाण** (Village Panchayat / Municipality): Confirms rooftop ownership.
- **आधार कार्ड** (UIDAI): Identity verification.

## आवेदन कैसे करें
### गेडा सोलर पोर्टल (online)
Register consumer number and select vendor at geda.goa.gov.in.
Link: https://geda.goa.gov.in

### विद्युत उप-संभाग कार्यालय (blockOffice)
Submit technical feasibility inspection form.

## सावधानियाँ
Installation must be performed by empanelled GEDA solar vendors.
